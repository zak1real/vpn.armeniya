# vpn-connect — страница подключения к VPN

Одна статическая страница `index.html`: как поставить клиент, кнопки «Открыть в Happ» / «Открыть в INCY», копирование ссылки и QR-код. Без сборки; QR рисует `qrcodejs` с cdnjs.

## Откуда берётся ссылка-подписка

По порядку приоритета:

1. `https://vpnarmeniya.site/#<subId>` — короткая личная ссылка: страница подставляет `subId` к `SUB_BASE` (`https://sub.vpnarmeniya.site/1qtCvsxhXj/`);
2. `#sub=https://…` — полная ссылка-подписка в адресе;
3. `?sub=https://…`;
4. константа `DEFAULT_SUB` в скрипте страницы.

Всё после `#` не уходит на сервер хостинга, поэтому в репозитории нет ни одной рабочей подписки. Без ссылки страница просит открыть личную ссылку, кнопки неактивны.

`subId` пользователя берётся из 3x-ui (на сервере — `/root/vpn-info.txt`, строки `SUB_*`: последняя часть адреса).

## Deep-link форматы

- Happ: `happ://add/<ссылка-подписки>`
- INCY: `incy://import/<ссылка-подписки>`

Меняются в объекте `APPS` в `index.html`. Если приложение не открылось за ~2 с, показывается подсказка установить его.
