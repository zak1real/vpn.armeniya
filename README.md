# vpn-connect — страница подключения к VPN

Одна статическая страница `index.html`: как поставить клиент, кнопки «Открыть в Happ» / «Открыть в INCY», копирование ссылки и QR-код. Без сборки; QR рисует `qrcodejs` с cdnjs, шрифт Manrope — Google Fonts (без него страница падает на системный шрифт).

## Приложения

Шаг 1 разбит на вкладки «iPhone / Android / Компьютер», нужная выбирается по устройству (`detectOs`).

- **iPhone** — Happ и INCY убраны из российского App Store (помечены «не в РФ», под ними инструкция про Apple ID другой страны). Из доступных в РФ: OneXray (`id6745748773`, Xray-core — работают все профили), Karing (`id6472431552`, sing-box — XHTTP может не работать), Shadowrocket (`id932747118`, платный).
- **Android** — Happ (Google Play), INCY (сайт).
- **Компьютер** — Happ, INCY (сайты).

Список меняется: перед правкой проверять, что карточки в App Store живы и издатель тот же.

## Откуда берётся ссылка-подписка

По порядку приоритета:

1. `https://vpnarmeniya.site/#<subId>` — короткая личная ссылка: страница подставляет `subId` к `SUB_BASE` (`https://sub.vpnarmeniya.site/1qtCvsxhXj/`);
2. `#sub=https://…` — полная ссылка-подписка в адресе;
3. `?sub=https://…`;
4. константа `DEFAULT_SUB` в скрипте страницы.

Всё после `#` не уходит на сервер хостинга, поэтому в репозитории нет ни одной рабочей подписки. Без ссылки страница просит открыть личную ссылку, кнопки неактивны.

`subId` пользователя берётся из 3x-ui (на сервере — `/root/vpn-info.txt`, строки `SUB_*`: последняя часть адреса).

## Deep-link форматы

- Happ: `happ://add/<ссылка-подписки>`
- INCY: `incy://import/<ссылка-подписки>`
- OneXray: `onexray://onexray.com/sub/add?url=<ссылка, URL-кодированная>` (из README OneXray)
- Karing: `karing://install-config?url=<ссылка, URL-кодированная>&name=Armenia%20VPN` (официально не задокументирован)

У Shadowrocket надёжного формата нет — для него и прочих клиентов под кнопками блок «Как добавить вручную» с пошаговыми инструкциями.

Меняются в объекте `APPS` в `index.html`. Если приложение не открылось за ~2 с, показывается подсказка установить его.
