Подключение к VPN

Сервер в Армении. Три шага: поставить приложение, нажать кнопку, включить.

Сервер настраивается — ссылка для подключения появится здесь.

1Установите приложение

Happ

iPhone / Mac Android Windows и другие

INCY

iPhone / Mac Android / Windows

Достаточно одного. INCY убрали из российского App Store — на iPhone с российским аккаунтом ставьте Happ.

2Добавьте подписку

Приложение не открылось? Установите его из шага 1 и нажмите кнопку ещё раз. Или скопируйте ссылку и добавьте её вручную: «+» → «Вставить из буфера».

С компьютера: отсканируйте QR-код в приложении на телефоне.

3Включите VPN

В приложении выберите сервер и нажмите большую кнопку подключения. При первом запуске телефон попросит разрешить добавление VPN-конфигурации — согласитесь.

Ссылка личная — не пересылайте её другим.
